# Font provenance

- `LilitaOne-Regular.ttf`: original, unchanged font from `https://raw.githubusercontent.com/google/fonts/main/ofl/lilitaone/LilitaOne-Regular.ttf`. Downloaded October 13, 2026 (America/Toronto). Retains `LilitaOne-OFL.txt` and its Reserved Font Name Lilita.
- `Nunito-Variable.ttf`: original, unchanged font from `https://raw.githubusercontent.com/google/fonts/main/ofl/nunito/Nunito%5Bwght%5D.ttf`. Downloaded October 13, 2026 (America/Toronto). Retains `Nunito-OFL.txt`.
- `Nunito-SemiBold.ttf`: static instance of that Nunito variable file with `wght=600`, generated by `tools/build_art.py` using fontTools 4.66.1. Names updated to Nunito SemiBold. The original Nunito OFL does not reserve a font name. It remains under the SIL Open Font License and is not covered by the generated assets' CC0 dedication.

All fonts are bundled locally. Playing, importing or exporting the Godot game requires no network font service. The original variable font remains available for regeneration, but the runtime uses the static weight so Godot's default variable-axis selection cannot make interface labels too thin.
